The six source specs disagreed in places. Canonical choices, applied everywhere below:

A1. WORLD STRUCTURE: 5 zones in ONE streamed world (from CONTENT spec). Each zone has its
    own egg pedestals + orb field. Zone gates are server-checked at travel pads. (Overrides
    the 4-zone / single-zone variants in ECONOMY/MONETIZATION.)
A2. PET ROSTER: the 33-pet CONTENT roster is canonical (ids, names, rarities, basePower).
A3. EGGS: 10 eggs (2 per zone) from CONTENT spec, with its costs/odds. (Overrides ECONOMY's
    6-egg list and MONETIZATION's 4-egg list.)
A4. MUTATIONS: 5 tiers None/Golden/Rainbow/Void/Celestial with mults 1/3/8/25/100
    (CONTENT). Fusion is DETERMINISTIC for v2 (no shiny/perfect fuse roll — that was optional).
A5. SHINY: independent 2.5% (1/40) roll on hatch, x1.5 power, cosmetic (CONTENT). VIP -> 5%.
A6. REBIRTH:
      RebirthCost(n) = 1,000,000 * 3.2^n   (n = current rebirths, 0-indexed) [ECONOMY]
      RebirthMult    = 1 + 0.75 * rebirths  [all specs agree]
      EquipSlots     = 3 + rebirths, capped at 10 from rebirths; +gamepass/tokens to hard cap 14.
A7. CLICK VALUE: clickValue = max(1, floor(0.10 * CPS)) * RebirthMult, server-clamped,
    12 clicks/sec cap. (Reconciles UX/CONTENT "0.10*CPS" with rebirth scaling.) No crit in v2.
A8. PRIMARY ACTIVE INCOME = ORB FIELDS (CONTENT), not click-spam. Clicking is a minor booster.
A9. DataStore key = "PetFusionV2", schema Version = 2, with V1->V2 migration (Section G).
A10. ITEM CURRENCY: Coins only (soft). RebirthTokens tracked but no shop in v2 (store the count).

PetData.power(pet) -> number
  -- pet = {Type, Mut, Shiny}. Returns BasePower * MutMult * (Shiny and 1.5 or 1).
  -- Does NOT apply rebirth/gamepass/index (server applies global mults to the SUM).
  local base = PetData.Pets[pet.Type].basePower
  return base * PetData.Mutations[pet.Mut].mult * (pet.Shiny and PetData.Config.ShinyMult or 1)

PetData.pickRarity(eggId, luck, rng) -> rarityString
  -- Build weights from Eggs[eggId].odds (x10 -> ints). For each rarity in the "rarer half"
  -- set, weight *= luck. Renormalize, weighted pick with rng (default math.random).

PetData.pickPet(eggId, luck, rng) -> {Type, Mut="None", Shiny=bool}
  -- rarity = pickRarity(...). candidates = pets in egg.pool with that rarity.
  -- If none (e.g. Volcano Common), step rarity UP one tier until candidates exist.
  -- Pick uniformly among candidates. Shiny = rng() < shinyChance (caller passes effective chance).
  -- SPECIAL: Forest Deluxe Secret -> whisperwing; Celestial Deluxe Secret -> 50/50 astral_serpent/the_architect;
  --          other eggs' Secret -> that pool's default Secret. Encode via per-egg secret override table inside fn.

PetData.nextMut(mut) -> string|nil      -- None->Golden->Rainbow->Void->Celestial->nil

PetData.rebirthCost(rebirths) -> number  -- math.floor(1000000 * 3.2 ^ rebirths)

PetData.rebirthMult(rebirths) -> number  -- 1 + 0.75 * rebirths

PetData.equipSlots(rebirths, gamepassBonus) -> number
  -- math.min(Config.EquipSlotsBase + math.min(rebirths, Config.EquipSlotsRebirthCap - Config.EquipSlotsBase) ...)
  -- Concretely: base 3 + min(rebirths,7) from rebirths (=>cap 10), + gamepassBonus, clamp <= 14.

PetData.clickValue(cps, rebirths) -> number   -- max(1, math.floor(0.10*cps)) * rebirthMult(rebirths)

PetData.zoneUnlocked(zoneIndex, coinsEarned, rebirths) -> bool
  -- coinsEarned >= gate.coins AND rebirths >= gate.rebirths

PetData.effectiveLuck(rebirths, gamepassLuckMult, potionMult) -> number
  -- L = 1 * gamepassLuckMult * potionMult * (1 + 0.02*rebirths capped at +0.5); clamp <= Config.LuckCap

PetData.format(n) -> string   -- 1,234 / 12.3K / 4.56M / 7.8B / 1.2T then aa,ab,ac... suffixes

WorldBuilder creates Folder "Remotes" in ReplicatedStorage with these children.

RemoteEvents (client -> server):
  ClickCoin        : fire()                         -- registers one crystal tap; server rate-limits 12/s
  HatchRequest     : fire(eggId:string, count:number)  -- count in {1,3,10,50}
  EquipPet         : fire(guid:string)
  UnequipPet       : fire(guid:string)
  FuseRequest      : fire(guids:{string,string,string})
  FuseAll          : fire()                          -- server fuses every complete triple
  SellPets         : fire(guids:{string})
  SellBulk         : fire(filter:string)             -- "Common"|"Unequipped"|"Unlocked"
  LockPet          : fire(guid:string, locked:bool)
  RebirthRequest   : fire()
  TravelTo         : fire(zoneIndex:number)          -- request zone travel (also via pad ProximityPrompt server-side)
  ClaimDaily       : fire()
  ClaimQuest       : fire(questId:string)
  ClaimPlaytime    : fire()
  ClaimIndexTier   : fire(poolName:string)           -- or "full100"
  UseBoostItem     : fire(itemId:string)             -- consumes a stored potion: "luck"|"coin"
  SetSetting       : fire(key:string, val:any)        -- cosmetic prefs (music/sfx/lowfx/reducedmotion/floats/autohatch)
  SetTutorialStep  : fire(step:number)                -- advance/complete onboarding (server validates gates)

RemoteEvents (server -> client):

  HatchResult      : fire(pets:{ {Type,Mut,Shiny,rarity} })  -- drives reveal animation

RemoteFunctions (client -> server, request/response):

SECTION I — SERVER LOOP / AUTHORITY  (ServerDev)
================================================================================
I1. ONE Heartbeat accumulator at 1s granularity ticks coins: every whole second,
    Coins += CPS (recompute CPS only on state change, else use cached).
    CPS = sum(equipped PetData.power) * rebirthMult(rebirths) * coinMultGamepasses
          * coinBoostActive * (1 + IndexBonus).
    Recompute on: equip/unequip, fuse, rebirth, hatch(no, only equip changes), gamepass grant,
    boost start/expire, index reward.
I2. Click: server validates 12/s token bucket; adds PetData.clickValue(CPS, rebirths) * coinMult.
I3. Hatch: validate afford (count*cost), egg's zone unlocked, count in {1,3,10,50} (50 needs
    AutoHatch gamepass or MegaHatch token consumed). Deduct, roll N pets via pickPet with
    effectiveLuck + effective shiny chance, add to Pets (respect inv caps; block at hard cap),
    fire HatchResult; if any Legendary/Secret -> BigHatch broadcast; mark index seen.
I4. Fuse / FuseAll: as H3 validation. Mark index seen for resulting mut's base pet (already seen).
I5. Rebirth: require Coins >= rebirthCost(rebirths). Set Coins=StartCoins, rebirths+=1,
    rebirthTokens+=1, recompute EquipSlots, recompute zone unlock bitmask, FX broadcast on
    every 10th. coinsEarned NOT reset.
I6. Travel: validate zoneUnlocked(target, coinsEarned, rebirths); teleport HRP to Arrival;
    set Zone attribute; on fail Notify shortfall.
I7. Orbs: server Touched (debounced per orb 4s) grants Zones[zone].orbValue * coinMult; FXEvent.
I8. Rate limits (token buckets): Click 12/s, Hatch 6/s, Fuse 4/s, Equip 10/s; reject + error toast.
I9. All Robux: UserOwnsGamePassAsync cached per session + refresh on PromptGamePassPurchaseFinished;
    ProcessReceipt idempotent (G5). No gamepass/product grants pets or guarantees Secret.
